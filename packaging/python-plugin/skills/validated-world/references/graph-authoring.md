# Graph authoring and ongoing context

Model independently changeable claims with stable IDs, source authority/evidence
and uncertainty. Organize the purpose-rooted scope tree around stable subjects.
Containment provides upstream context; explicit directed dependency edges select
consequential claims. Link directly to the exact relied-on facts across any scope
depth and record direction/rationale. Avoid catch-all links that select unrelated claims.

For five continents, separate the mutable set/count from stable geography and
world identity. John's boast and Darrell's count-dependent dialogue depend on the
set/count; Tod's river dialogue depends on geography. Adding a continent selects
count-dependent claims. Editing Darrell's dialogue includes his full upstream
character context and ordinary dependency propagation selects further consequences.
An unchanged context ancestor does not select siblings; directly editing it does
select its subtree. No special dialogue mechanism is required.

Avoid duplicated mutable counts when a canonical aggregate/reference suffices.
Where prose needs the count, preserve its links. Existing validation views and
count/set rules check structured evidence, not prose truth or missing links.
Search alternate names, synonyms and count wording for plausible missing links.
A broad scope/purpose review remains available through multiple packets in one
atomic change. A keyword sweep cannot establish completeness.

Each new agent verifies identity/state, retrieves relevant context, and saves
useful durable facts/decisions and dependencies with evidence through reviewed
updates. Preserve uncertainty for the next task; keep transient transcripts out
of canonical knowledge. Hosts supply orchestration and connected tools; the
skill maintains the local knowledge workflow.
