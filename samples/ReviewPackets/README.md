# Review packet smoke foundation

Create a disposable game-world documentation file with Python 3.12+:

```text
python samples/ReviewPackets/create_fixture.py <new-absolute-html-path>
```

Use `--extra-npcs 1000` for a broader purpose-change review. Data is fictional
and sanitized. Change the continent count, add a sixth continent and revise the
count rule/dialogue in one proposal. John and Darrell have precise dependencies;
Tod relies on river geography. An intentionally unlinked claim demonstrates
that propagation cannot detect missing links. Also try a full purpose change,
packet refinement, context requests and a stale external writer. This is a
repeatable starting graph for informal exploration, not a fixed smoke script.
