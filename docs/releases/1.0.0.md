# ValidatedWorld 1.0.0

First public release of the open-source ValidatedWorld agent skill, packaged as
a standalone skill and a skills-only plugin.

- Ask your agent to create and maintain connected project documentation in
  `docs-vw.html`, with bounded retrieval and consequence review before saving.
- Browse the same self-contained HTML file directly in a browser.
- Run the bundled standard-library Python engine without pip installation,
  third-party runtime dependencies or a separate product API key.
- Use persistent response logging, reviewed atomic changes and recoverable
  document publication, with normal temporary-workspace cleanup.

The maintainer reports successful use on separate computers with ChatGPT Plus
and Free accounts. Python 3.11+,
project-file access, persistent processes and fresh read-only subagents are
required; the agent host controls model access, usage limits and data handling.

Version 1.0.0 establishes the `validated-world-document-2` compatibility baseline.
Later 1.x releases must preserve valid 1.x documents; incompatible format changes
require a new major version and documented conversion instructions. Review
depends on recorded links and does not prove that claims are true.

Release validation passed 178 unit tests with 90% branch coverage, isolated
Python 3.11 package checks for both archives, Windows hard-link restriction and
temporary-path alias regressions, and final-package author/review/save checks
with an actual fresh subagent. The generated document also passed a local
browser navigation and deep-link reload check.

## Downloads

- `validated-world-skill-1.0.0.zip`: extract the entire archive into the host's
  `validated-world` skill folder, with `SKILL.md` directly inside it.
- `validated-world-python-plugin-1.0.0.zip`: complete plugin package for plugin
  installation and OpenAI submission.
- `SHA256SUMS.txt`: SHA-256 checksums for both archives.

The repository's automatic source ZIP is not the installable skill archive.
See [installation](https://github.com/mcdanieladamg/ValidatedWorld/blob/main/docs/release_distribution.md),
[support](https://github.com/mcdanieladamg/ValidatedWorld/blob/main/docs/support.md) and
[host acceptance](https://github.com/mcdanieladamg/ValidatedWorld/blob/main/docs/host_acceptance.md).
OpenAI directory publication remains
subject to separate submission and approval.
