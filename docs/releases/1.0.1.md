# ValidatedWorld 1.0.1

This patch updates the plugin listing and documentation to describe compatibility
through the capabilities the skill needs: Python 3.11+, project-file access,
persistent processes and fresh read-only subagents for reviewed updates.

- Remove Windows-only support wording and separate-acceptance caveats from the
  listing, bundled README, support page and installation documentation.
- Keep the same standard-library Python engine and author/review/save workflow.
- Preserve the 1.x document compatibility contract established in 1.0.0.

Validation passed all five package-metadata tests and both archives' Python 3.11
installation, author/review/save, permission-regression and temporary-path alias
checks. Checksums and packaged source consistency were verified.

Report compatibility problems through
[GitHub Issues](https://github.com/mcdanieladamg/ValidatedWorld/issues) with the
package version, agent client, operating system, Python version and a small
sanitized example.

## Downloads

- `validated-world-skill-1.0.1.zip`: the complete standalone skill.
- `validated-world-python-plugin-1.0.1.zip`: the complete plugin package for
  plugin installation and OpenAI submission.
- `SHA256SUMS.txt`: SHA-256 checksums for both archives.
