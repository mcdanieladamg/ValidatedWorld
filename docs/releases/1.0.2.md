# ValidatedWorld 1.0.2

The plugin listing now describes the skill's purpose: graph-wide conceptual
consistency beyond an agent's context window, with targeted retrieval and
batched reviews by fresh sub-agents before changes propagate.
It also highlights the human-friendly HTML file for browsing the graph.

- Simplify the public listing and bundled introduction around what users can do.
- Use `validated-world` as the package identifier and **ValidatedWorld** as the
  display name. Remove migration suffixes from the source layout, archive names,
  build tools and installer.
- Recommend English for stored workflow guidance rather than requiring it,
  consistently in the skill and command help.
- Keep the existing graph engine, author/review/save workflow and 1.x document
  compatibility contract.

Validation passed all 180 unit tests with 90% branch coverage, including package
identity checks and a mocked local-installation regression, plus developer and
blueprint checks, both skill validators and both archives' isolated Python 3.11
author/review/save and temporary-directory alias checks. Packaged sources,
checksums, documentation links and the reviewed project-design delta were verified.
