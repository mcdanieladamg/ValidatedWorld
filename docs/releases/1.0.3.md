# ValidatedWorld 1.0.3

ValidatedWorld keeps an AI agent's connected project knowledge consistent beyond
its context window, with targeted retrieval, batched independent review and a
human-friendly HTML graph stored in the project.

- Keep SQLite working state, proposals, approvals and review packets entirely
  in memory. Ordinary skill use creates no temporary folders or working files.
- Preserve fresh-subagent approvals, lossless batching, supplemental context,
  refinement and independent synthesis before a coherent reviewed save.
- Use native persistent pipes by default, with optional in-memory local command
  and read-only packet transports.
- Save directly to the selected HTML after review. Unsaved work disappears with
  the process; an interrupted save can leave partial HTML.
- Preserve compatibility with valid 1.x documents and explicit DB authority.
- Remove reverse-DNS lookups from local transport startup to avoid resolver
  delays before the controller can announce its URL. Add startup diagnostics and
  regressions for environments where DNS is unavailable.

Validation passed 168 tests with 90% branch coverage, including both DNS-denied
startup regressions. Both 1.0.3 archives passed isolated author/review/save
workflows allowing only the selected HTML to be written, plus temporary-path
alias checks. The in-memory implementation also retains the previous live fresh
branch/synthesis review and browser verification. Graph-engine behavior and
document format are unchanged.
