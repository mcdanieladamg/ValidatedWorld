# ValidatedWorld 1.0.3

ValidatedWorld keeps connected project knowledge consistent beyond an agent's
context window through targeted retrieval, batched fresh review and a browsable
HTML graph stored in the project.

- Ordinary skill use changes only the selected HTML. Drafts, controller state,
  proposals and complete responses/evidence remain in memory. No temporary
  controller scripts, proposal dumps, response logs, handoff files or working
  folders are created. Explicitly requested backups/conversions remain supported.
- Replace compressed file handoffs and HTTP URL controllers/reviewer endpoints
  with read-only native IPC and explicit exact messages. Windows uses named pipes,
  Linux uses abstract sockets with no disk entry, and macOS uses a numeric local
  byte socket. Confirm access from the actual reviewer environment.
- Deliver bounded, hashed affected/context and terminal packet pages directly
  from RAM. Preserve lossless batching/refinement, complete coverage, exact
  bindings, fresh independent branch reviews and a separate synthesis gate.
- Retain one authoring child through saving; restarting loses its session and
  proposal. Validate complete NDJSON envelopes before accessing payload, while
  preserving valid list responses and compact affected pagination summaries.
- Emit exact UTF-8 packet bytes through the reader CLI on Windows so line-ending
  conversion cannot invalidate hashes. Reject stale/revoked evidence, incorrect
  capabilities, malformed control frames and incomplete reviews.
- Preserve project-folder confinement, Unicode data, guarded direct saving,
  existing 1.x document compatibility and the approved public plugin description.

Windows validation passed 183 tests at 90.24% branch coverage, 21 developer-tool
cases, canonical/blueprint checks, both candidate archives and temporary-path
alias checks. Four fresh branch reviewers and a separate fresh synthesis reviewer
fetched all 29 terminal packet pages, verified exact hashes/bindings and enabled
a guarded save. Verification, Unicode read-back, revocation and browser checks
passed; ordinary shutdown left only the selected HTML. This host required narrowly
approved read-only pipe access after sandbox denial. Linux/macOS execution and
security analysis are left to CI. The external payload-only-wrapper
explanation remains a hypothesis because its controller and traceback were not
provided. Native IPC cannot bridge inaccessible host environments; exact messages
and lossless batching require actual host context capacity and never permit
truncating required evidence or substituting same-context approval.
