# ValidatedWorld 1.0.3

ValidatedWorld keeps an AI agent's connected project knowledge consistent beyond
its context window, with targeted retrieval, batched independent review and a
human-friendly HTML graph stored in the project.

- Keep authoring, review and saving together in one persistent session.
- Preserve fresh-subagent approvals, lossless batching, supplemental context,
  refinement and independent synthesis before a coherent reviewed save.
- Clarify how agents start and retain an authoring session, parse replies and
  verify saved changes. A local HTTP controller remains available when permitted.
- Default to compressed project-local evidence handoffs so fresh reviewers can
  read complete packets independently without socket access. Keep exact bindings,
  fixed-size receipts covering every page, branch coverage and separate synthesis
  before saving.
- Keep complete controller replies outside the author's conversation context;
  display compact status and counts by default. Clean up owned review artifacts
  after saving, discarding or handled shutdown.
- Correct compact affected-page totals and continuation flags when evidence spans
  multiple pages.
- Confine persistent-session reads and writes to the project folder selected
  at startup and its subfolders. Reject traversal, linked paths, Windows
  device/stream aliases and request-level attempts to expand file access.
  Templates, backups, exports and normal review continue inside that boundary.
- Save reviewed project knowledge to the selected HTML and verify the result.
  Ending a session loses unfinished proposals; an interrupted save can leave
  partial HTML.
- Preserve compatibility with valid 1.x documents and explicit DB authority.
- Remove reverse-DNS lookups from local transport startup to avoid resolver
  delays before the controller can announce its URL. Add startup diagnostics and
  regressions for environments where DNS is unavailable.

Validation passed 186 tests with 90.68% branch coverage, including DNS-denied
startup, project-folder boundaries and socket-denied file review. Both 1.0.3
archives passed isolated author/review/save workflows allowing only the selected
HTML to be written, plus temporary-path
alias checks. A separate candidate trial passed fresh host review, guarded saving
and browser verification. Existing branch/synthesis review coverage remains.
Graph-engine behavior and document format are unchanged.
