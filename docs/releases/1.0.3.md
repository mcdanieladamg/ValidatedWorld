# ValidatedWorld 1.0.3

Ordinary HTML work uses one hidden temporary companion whose name follows the
selected document: `design.html` uses `.design.tmp.html`. The document name is
customizable; `docs-vw.html` remains the default.

- Keep working SQLite state in memory. Share live responses, review evidence,
  publication staging and recoverable unpublished state through the companion.
- Coordinate concurrent readers and reject competing writers. Remove owned
  temporary data after successful completion; protect active, unknown and
  unpublished recovery data on startup.
- Fix POSIX lock coordination across different process temp settings and protect
  replacement files when Linux would otherwise recycle an unlinked inode.
- Exercise native lease failure and cleanup paths on every CI platform, keeping
  the existing 90% branch-coverage requirement.
- Send large terminal requests as short, checksum-verified input frames. Assemble
  the complete request in memory before dispatch, without extra temporary files.
- Preserve explicit backups, trusted database workflows and requested working
  database retention. Disposable development checks remain separate from normal
  installed-skill operation.
- Preserve the exact public OpenAI listing description and 1.x document format.
- Generate both archives, release notes and checksums together. Validate all
  three checksums before package extraction.

Windows validation covers the unit suite with branch coverage, developer and
blueprint checks, isolated workflows in both archives, temporary-path aliases,
fresh host review and browser exploration. Linux and macOS were not run locally;
local checks do not establish OpenAI submission approval.
