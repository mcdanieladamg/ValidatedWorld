# ValidatedWorld 1.0.3

This replacement build simplifies the skill around HTML authoring with independent
subagent reviews. The public plugin listing description is unchanged.

- Use one bundled retained-session helper that keeps complete responses in memory
  and automatically tracks the latest proposal reference.
- Give fresh reviewers ordinary file access to complete bounded packets in one
  hidden companion HTML. Remove network, localhost, native-channel and large
  message handoffs from the product workflow.
- Preserve batching, refinements, complete impact/context coverage, supplemental
  evidence, exact proposal bindings, branch reviews and a separate fresh synthesis.
- Reuse the single companion for a flushed and verified candidate, then atomically
  replace the selected HTML. Remove owned work on save, discard or graceful exit;
  recognize abandoned work on startup and preserve unknown data.
- Create no temporary controllers, logs, evidence folders or automatic backups.
  Explicitly requested backups/conversions and manual DB compatibility remain.

Reviewers need ordinary read access to the selected project folder and the host
must support fresh subagents. Bounded pages avoid copying entire packets through
the author's context. One coherent synthesis still needs enough model context to
reason about the assigned global evidence; batching does not remove that limit.

Local Windows validation passed 180 tests with 90.04% branch coverage, developer
and blueprint checks, both isolated archive workflows and temporary-path alias
checks. An actual 45-node/81-edge garden trial passed three simultaneous fresh
branch reviews plus separate fresh synthesis, guarded saving, verification and
cleanup to the single saved HTML. Browser-only localhost preview timed out after
its diagnostic retry; no browser smoke pass or other-platform execution is claimed.
The canonical graph correction changed 26 node texts while preserving all IDs,
edges, tags, attributes and the completed roadmap.
